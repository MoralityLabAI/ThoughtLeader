# Intact original pilot and art recovered

Following the author's reminder about the Claude-era pixel-art style, an additional targeted search on 2026-09-11 located an intact earlier **clean checkout** of `https://github.com/patrickdugan/ThoughtLeader`, at commit `c8136095bb08e4b8a512560c8ca47e18b61f36b5`.

Its 27 project files (13,891,988 bytes) were copied without editing into `original-pilot/`; the source checkout and damaged E-drive originals were not changed. The archive includes the complete earlier pilot's structured world, theater HTML, character sheet, sprite generators and data, reference images, tooling and documentation. It does not contain the later episode 2–6 sprite scripts named in the damaged dump.

This materially improves the recovery: the original **pilot and visual system**, not just observed playtest prose, now survive in this repository. It does not establish restoration of six original completed worlds. The current six-case draft remains an adaptation of the author's revised outline; this art restoration does not silently substitute the historical pilot's plot or mechanics for it.

The original artwork is an indexed 48×56 portrait system with animation patches and procedural 320×180 rooms. Its shared palette and source are now used by the active [pixel theater](../assets/pixel/README.md), alongside newly authored settings for all six cases. Source hashes in the art manifest identify the recovered inputs.

The old README includes dated claims about prototype completeness and pending work. Preserve those as historical documentation, not current verification results. The rebuilt season's checks remain in `season1/reports/`.
